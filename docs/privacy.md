# Privacy

Dreamcamera runs locally in the browser.

## Data collected

No analytics are enabled in v1. The app does not send camera frames, model inputs, generated frames, or local settings to a server.

## Local storage

The app may store preferences and optional user-provided model pack metadata in browser storage. Users can remove this data through browser site settings.

## Network requests

The static app is loaded from GitHub Pages. Optional MediaPipe and ONNX/WASM assets may be fetched from public package or model URLs when the user starts the experience.
